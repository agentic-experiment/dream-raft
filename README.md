# dream-raft

*a drift through sleeping seas*

## Step-by-step reasoning

**1. What is this game?**
The name suggests the concept: a raft, but a dreaming one. The player pilots a small raft
across an endless, procedurally-dreaming sea — gathering glowing "fragments" of light,
evading nightmares, and drifting as far as possible before the raft's light gutters out.
An endless drifter: simple to learn, tense to survive, impossible to finish.

**2. Constraints first.**
It must run on GitHub Pages. That means static files only: no build step, no server logic,
no installs for the visitor, no external assets that could break. So the entire game is
plain HTML/CSS/JS served as-is.

**3. Technology choices.**
- Vanilla JavaScript + Canvas 2D for rendering — no framework, no library, no download.
  Canvas gives direct control over the dreamy additive-glow look and runs anywhere.
- Web Audio API for sound — the pad, chimes, and thuds are synthesized on the fly, so
  there are zero audio files.
- System serif fonts only — no webfont requests.
- `localStorage` for the best score.

**4. Visual design (the "beautiful" requirement).**
Beauty here is atmosphere: a slow-shifting dream palette (the hue rotates as you drift),
aurora bands drawn with additive blending, a soft cratered moon, twinkling parallax stars,
silhouette islands with lit windows, layered sine-wave water with glowing surface lines, a
lantern-lit raft with a tiny dreamer curled aboard, sparkles, embers, ripples, and a
vignette. Every frame is procedural — there are no image assets at all.

**5. Gameplay systems.**
- Steer with ←/→ (or A/D), or drag on touch. Hold Space to drift faster — but the light
  burns quicker while boosting.
- Fragments: +score (with a combo multiplier for quick chains, up to 5x), +light, and a
  gentle magnetic pickup.
- Nightmares: dark tendril-creatures that chase the raft; each hit costs light and breaks
  the combo. Light also slowly drains, so you must keep gathering.
- Difficulty ramps with distance: scroll speed rises and spawns get denser.
- Score accrues with distance too; the best score persists between sessions.
- Flavor: each fragment has a chance to whisper a dream fragment ("a staircase made of
  rain", "the sound of a color") into the corner of the screen.

**6. Structure.**
- `index.html` — canvas, HUD, overlay screens (title / pause / game over).
- `style.css` — layout, HUD, overlay, animations.
- `game.js` — everything else: input, audio, entities, rendering, game loop.
- `README.md` — this file.

**7. Sound.**
A quiet detuned pad (three oscillators through a slow-swept lowpass filter) sits under
everything; pentatonic chimes on pickup (pitch climbs with the combo), a low thud on
nightmare hits, and a descending cadence when the raft fades. `M` toggles mute. The audio
context is created on the first user gesture, per browser autoplay rules.

**8. Small courtesies.**
Auto-pause when the tab hides, `P`/`Esc` to pause, `R` to restart, high-DPI rendering,
`prefers-reduced-motion` disables screen shake, and pointer events give unified
mouse/touch steering.

## Controls

- ← → / A D, or drag — steer
- Space (hold) — drift faster (burns light)
- M — mute · P / Esc — pause · R — restart after game over
